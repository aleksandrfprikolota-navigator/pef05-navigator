# ИИ-ассистент «Навигатор»

Telegram-бот с поиском по публичным материалам двух контуров: личная практика Александра Приколоты (komfortnavigator.ru) и сервисы ООО «1С-Премиум» (1c-prem.ru). Ответ строится только по найденным фрагментам. Если опоры нет, бот отказывается фиксированной фразой и предлагает заявку.

Автор: Приколота Александр Фёдорович. Основание: техническое задание версии 1.3 от 31.10.2026. Съём резюме обновлён в тот же день: в PDF и на сайте срок в ООО «1С-Премиум» совпадает — июль 2024, по настоящее время.

## Запуск локально

Нужны Docker Desktop и Python 3.11 или 3.12. В контейнере сервис собран на Python 3.12, как в ТЗ.

```text
docker compose up -d db
python -m app.indexer
python -m app.cli "Сколько стоит часовая консультация?"
python -m app.bot
```

На этой машине контейнер базы открыт на порту 5433: 5432 уже был занят другим PostgreSQL. Внутри Docker бот по-прежнему ходит в `db:5432`.

Ключ OpenAI и токен бота лежат в `.env`. Файл не коммитится. Действующий бот @ExpertDigitalProductsAndBPA_bot не используется: для «Навигатора» нужен отдельный токен из BotFather. Свой Telegram ID бот показывает по команде `/id`. Его нужно записать в `OWNER_TELEGRAM_ID`, иначе карточка заявки сохранится в базе, но в чат владельца не уйдёт.

Команды владельца: `/reindex`, `/spend`, `/sources`, `/generation on`, `/generation off`.

## Где работает бот

С 31.10.2026 бот @AI_KomfortNavigator_bot запущен на том же сервере, что и komfortnavigator.ru: `147.45.150.56`, Timeweb, Москва. Каталог на сервере — `/opt/navigator`, файл `docker-compose.vps.yml`, имя проекта Compose — `navigator`. Стек сайта и Caddy не входят в этот проект. Действующий бот сайта не перенастраивался.

PostgreSQL слушает только `127.0.0.1:5432`. Заявки и журнал остаются на этой машине в России. После перезагрузки сервера бот поднимается сам: Docker включён в автозагрузку, у базы и у бота политика `unless-stopped`. Если база встаёт позже процесса, бот ждёт её до одной минуты.

OpenAI с московского адреса этого дата-центра отвечает отказом по региону. Контейнер бота вызывает официальный `https://api.openai.com` через privoxy на порту 8118, а privoxy отправляет трафик в SSH SOCKS на сервер владельца `72.56.100.17`. Службы `openai-socks` и `privoxy` включены в автозагрузку. Прокси слушает localhost и адрес моста Docker, в интернет он не опубликован. Telegram long polling идёт из контейнера напрямую.

Ключи лежат в серверном `.env` и в git не попадают. Ноутбучный `.env` на сервер копировать нельзя: пароль базы там свой, а запросы к API на сервере обязаны идти через прокси.

Строка VPS 1 200 ₽ в смете — оценка отдельной машины. На запущенном контуре второй сервер не арендован: бот стоит на уже оплаченном сервере сайта.

Ежедневный дамп базы по ТЗ хранится 14 дней на этом же контуре или у владельца. Домен и HTTPS боту не нужны: он забирает сообщения long polling.
