# ИИ-ассистент «Навигатор»

Telegram-бот с поиском по публичным материалам двух контуров: личная практика Александра Приколоты (komfortnavigator.ru) и сервисы ООО «1С-Премиум» (1c-prem.ru). Ответ строится только по найденным фрагментам. Если опоры нет, бот отказывается фиксированной фразой и предлагает заявку.

Автор: Приколота Александр Фёдорович. Основание: техническое задание версии 1.2 от 30.10.2026. Съём резюме обновлён 31.10.2026: в PDF и на сайте срок в ООО «1С-Премиум» совпадает — июль 2024, по настоящее время.

## Запуск локально

Нужны Docker Desktop и Python 3.11 или 3.12. В контейнере сервис собран на Python 3.12, как в ТЗ.

```text
docker compose up -d db
python -m app.indexer
python -m app.cli "Сколько стоит часовая консультация?"
python -m app.bot
```

На этой машине контейнер базы открыт на порту 5433: 5432 уже был занят другим PostgreSQL. Внутри Docker бот по-прежнему ходит в `db:5432`.

Ключ OpenAI и токен бота лежат в `.env`. Файл не коммитится. Действующий бот @ExpertDigitalProductsAndBPA_bot не используется: для «Навигатора» нужен отдельный токен из BotFather. Свой Telegram ID бот показывает по команде `/id`. Его нужно записать в `OWNER_TELEGRAM_ID`, иначе карточка заявки сохранится в базе, но в чат владельца не уйдёт.

Команды владельца: `/reindex`, `/spend`, `/sources`, `/generation on`, `/generation off`.

На VPS тот же каталог поднимается целиком:

```text
docker compose up -d --build
```

Тогда бот ходит в PostgreSQL по адресу `db`, а не `localhost`.

## Куда ставить бота

Заявки — это персональные данные. Их место по ТЗ — PostgreSQL на VPS в России, не зарубежный хостинг.

Практичный вариант под уже посчитанный бюджет 1 200 ₽ в месяц: виртуальный сервер Timeweb Cloud в Москве, 2 vCPU и 2 ГБ памяти. Этого хватает на один контейнер бота и PostgreSQL с pgvector. Домен и HTTPS для первой версии не нужны: бот забирает сообщения long polling. Ежедневный дамп базы хранить на этом же сервере или у себя, 14 дней.

Тот же контур дают Selectel, Yandex Cloud и VK Cloud, если нужен договор с более формальным контуром 152-ФЗ. Менять модель на YandexGPT из-за выбора хостера не нужно: хостинг и модель в ТЗ разделены.

Railway, Render и Fly.io для этого бота не подходят: карточка заявки уехала бы из России.
